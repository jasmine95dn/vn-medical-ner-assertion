# Data & Fine-tuning Strategy — for a future attempt

> Retrospective from the first attempt (blind few-shot, best score **22.54**).
> The competition **expects contestants to generate training data and train the
> ≤9B model** ("dùng giải pháp ngoài lời giải chính để tạo thêm dữ liệu huấn
> luyện mô hình"). The main *inference* solution stays ≤9B self-hosted / no
> external API; **data creation** may use outside methods. Blind few-shot was the
> wrong frame — the intended play is **distillation / weak supervision + fine-tune**.

## What we learned (locked facts about the ground truth, from 4 submissions)
- ICD candidate format uses the **dot** (`D55.0`), not `D550`.
- Ground truth is **no-dedupe** (keeps every mention; removing repeats hurt: 22.54 → 17.27).
- Removing clear **junk** (dosing/generic/genetic-mechanism) helps; over-pruning legit spans hurts.
- Metric weights: **candidates 0.4**, text (WER) 0.3, assertions 0.3. Our candidates were
  the weakest (J≈0.13) and are the highest-weight → biggest ROI.

## Metric reminder
`final = 0.3·(1−WER) + 0.3·J_assertion + 0.4·J_candidates`. Wrong text/type ⇒ concept
counts twice, 0 on all three ⇒ everything is gated by concept text/type matching gt.

---

## Weak supervision with Snorkel — where it fits
Snorkel = write noisy labeling functions (LFs); `LabelModel` learns their accuracies
and combines them without gold labels.

- ✅ **Assertion** (isNegated/isFamily/isHistorical): the classic Snorkel/ConText/NegEx use
  case. Turn `assertion_triggers.json` into LFs; add negative LFs for false triggers
  ("không khí", "em"=first person, "Người nhà cho biết…") from `negative_examples.json`.
- ✅ **Type classification** of an existing span (dict/lexicon LFs → 5 types).
- ❌ **Span detection**: Snorkel classifies, it does not cut spans → need candidate spans first.
- ❌ **Candidate linking** (ICD/RxNorm code): use retrieval, not Snorkel.
- 💡 **LLM-as-LF**: use a strong model as one LF; LabelModel weights it against rule LFs.
  Snorkel itself needs no external API (safe re: rules).

## Pipeline
```
1. Raw VN medical corpus
2. Candidate spans  = dict-match (ICD + drug lexicon) + underthesea chunks + 8B proposals
3. Snorkel LabelModel #1  → keep? + TYPE per span
4. Snorkel LabelModel #2  → assertions (trigger LFs + negative-trigger LFs)
5. Candidate codes  = embedding retrieval + VN-drug→RxNorm dict + ICD-10 index
6. Silver dataset   → QLoRA fine-tune Qwen3-8B (T4-friendly)
7. Inference with the fine-tuned ≤9B model (obeys the self-host constraint)
```

## Data sources

### Raw VN medical text to pseudo-label (base corpus)
- `hungnm/vietnamese-medical-qa` (9.3k real QA) — FAQ prose.
- `urnus11/Vietnamese-Healthcare` (QA + Vinmec articles).
- Scrapes: Vinmec, Hello Bacsi, thuốc.vn.
- `PhoNER_COVID19` — has text + SYMPTOM_AND_DISEASE labels.
- Synthetic **bệnh án** (clinical notes) generated by a strong LLM in the test style
  (public VN clinical notes are scarce due to privacy).

### Labeled NER to remap into the 5-type schema
- **ViMQ** (github.com/tadeephuy/ViMQ) — VN medical-question NER; remap types.
- **PhoNER_COVID19** — take disease/symptom entities.
- **acrDrAid** (135 abbrev sets) — augment abbreviations (COPD/ĐTĐ/NMCT…).

### Assertion (= i2b2 2010 assertion task!)
- `isNegated/isFamily/isHistorical` map to i2b2 negated/family/historical.
- Translate/transfer **i2b2, n2c2** assertion data to VN, or auto-label via ConText/NegEx
  adapted with our Vietnamese trigger list.

### Candidate codes (40% weight — highest ROI)
- **ICD-10 VN** (already have, 12k terms) → VN disease phrasing → ICD code pairs.
- **RxNorm** is English-only → build a **VN drug dictionary: brand → active ingredient →
  RxNorm CUI** (DrugBank, thuốc.vn, danh mục thuốc BYT). This dictionary is the single
  most valuable data asset for the drug-candidate step.
- **UMLS** to bridge concepts → ICD/RxNorm.

## Priorities (by ROI)
1. **Hand-labeled dev set (50–100 sentences)** — measure locally instead of burning the
   ~5 submissions/day. Do this FIRST.
2. **VN drug→RxNorm + disease→ICD dictionaries** — attacks the 40% candidate score directly.
3. **Snorkel silver labels** (assertion + type) → QLoRA fine-tune.
4. Abbreviation augmentation (acrDrAid) + i2b2 assertion transfer.
